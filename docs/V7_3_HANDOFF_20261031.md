## 目的
旧版の主目的であるタブ削減と、4状態（未読/追跡中/保留/読了）を維持し、日常操作とバックアップ復元の負担を減らす。

## 変更内容
1. 作品カードに「＋1話読了」を追加、直前の操作のみ画面下部から取り消し可能。未読から読み進めた場合は追跡中へ変更し、取り消すと元の状態へ戻る。
2. デフォルトの並び順を「未読優先」とし、追跡中かつ未読話あり → 未読状態 → 追跡中 → 保留 → 読了。旧ソート項目も保持。
3. 「最新話まで読了」はカードの「その他」へ移動し、スマホ画面の主ボタンは「続きから読む」「＋1話読了」に絞る。
4. エクスポートJSONに日時付きファイル名を設定。`version:5` のJSONを出力するが、旧版の配列および`version:4`など `books` 配列を持つJSONの読み込みに対応。
5. 復元時に件数、重複除外後件数、統合時追加件数をプレビュー。既定は現行の読了記録を優先する統合。全件置換は別の明示的選択。
6. 復元前に `narou_shelf_pre_restore` へ現在の本棚を1世代退避し、その書き込みが失敗した場合は本棚を変更しない。
7. 復元作品のURL重複だけでなく、別作品間のID衝突を回避。
8. HTML属性の作品IDはエスケープし、カード内の操作はイベント委譲に変更。狭い画面用CSSとフォーカス表示を改善。
9. Service Workerキャッシュ名を`narou-shelf-v7.3`へ変更。

## 非変更
- `localStorage`の正本キー `narou_shelf_mvp_v3`、v1/v2からの移行、作品情報取得API、通常は追跡中のみ更新する規則は維持。
- 独自縦書きビューア、ブラウザ閲覧位置の自動追跡、取得キャッシュ/再取得省略は追加しない。
- 本番公開とデータ移行は未実施。
