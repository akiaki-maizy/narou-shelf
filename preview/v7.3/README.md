# なろう本棚 Ver.7.3 検証用プレビュー

正式版: https://akiaki-maizy.github.io/narou-shelf/
検証用: https://akiaki-maizy.github.io/narou-shelf/preview/v7.3/

## データ保護
- このプレビューの保存キーは `narou_shelf_preview_v7_3_data`。正式版の `narou_shelf_mvp_v3`、旧版の正本キー等を読み書きしない。
- Service Workerのスコープは `/narou-shelf/preview/v7.3/` に限定する。
- プレビューのキャッシュは `narou-shelf-preview-` 接頭辞のものだけを管理する。正式版の `narou-shelf-v7.2` を消去しない。
- 初回に架空のサンプル3作品をセットする。サンプルの作品URLは動作確認対象ではない。
- 誤って実データを取り込まないよう、`previewOnly:true` マーカーがあるJSON以外のインポートを拒否する。
- プレビューのバックアップ名は `narou_shelf_preview_backup_<日時>.json`。検証用の旧式v4サンプルは「その他」→「検証用JSONを保存」で取得。
- テストデータ初期化は「その他」→「テストデータ初期化」から実施する。プレビュー用データだけ書き換える。

## Androidでの手動確認
1. FirefoxまたはChromeから検証用URLを開き、「v7.3 検証用」とサンプル3作品が表示されること。
2. 「追跡中の作品」で「＋1話読了」を押し、進捗が5→6になること。その後「元に戻す」で5に戻ること。
3. 「未読の作品」で「＋1話読了」を押し、状態が追跡中に変わること。取り消すと未読に戻ること。
4. 更新順・未読優先・未読数順の切り替えと、スマホの狭幅表示、その他メニューを確認。
5. 「その他」→「検証用JSONを保存」→「復元」→ダウンロードしたJSONを選ぶ。統合を選ぶとサンプルの既存作品の進捗は維持され、新しい作品が1件追加される。
6. 「バックアップ」でプレビュー専用JSONを端末へ保存し、ファイル名に日時があることを確認。
7. 検証用JSONの再インポート・再読み込み・アプリ再起動でデータが維持されること。
8. 正式版のURLを開いて作品件数・読了位置に変化がないこと。正式版のバックアップをプレビューに取り込まない。
9. Chromeの「ホーム画面に追加」が利用可能なら、検証用を別名のアプリとして追加して起動できること。

**注意**: 本検証ページは公開URLで誰でもアクセスできる静的ページ。実作品の個人データは検証目的では登録せず、サンプルを使用する。
